# Agent Env Scripts

This directory owns reusable agent-env entrypoints that are not tied to a
single training run profile.

## Offline Rollout Collection

- `collect_env_rollouts.py` is the generic collector. It calls an existing
  env server/router `/run_episode` endpoint and drives the policy through an
  OpenAI-compatible chat-completions endpoint.
- `collect_tau2_rollouts.sh` is a tau2 convenience wrapper. It can generate
  tau2 prompt data, calls the generic collector with `--include-trace`, and
  writes both raw rollouts and compact teacher rows.

The collector does not start aux, env servers, Ray, or Slime training. Start
the required env server first. For tau2, that env server must already be
configured with its user-sim aux endpoint.

Typical tau2 usage:

```bash
AGENT_ENV_SERVER_URL=http://<env-host>:19000 \
POLICY_BASE_URL=https://<teacher-endpoint> \
POLICY_MODEL=<teacher-model> \
OPENAI_API_KEY_PATH=/path/to/key \
PROMPT_NUM_TASKS=128 \
COLLECT_CONCURRENCY=16 \
bash examples/agent_env/scripts/collect_tau2_rollouts.sh
```

Outputs are written under `${ROOT_DIR}/runs/teacher_rollouts/tau2/<stamp>/` by
default:

- `prompt_data/*.jsonl`: prompt rows used for collection when generated by the
  wrapper.
- `rollouts.jsonl`: raw env-server responses, including full traces when the
  server supports them.
- `teacher.jsonl`: compact teacher rows keyed by `task_id`, suitable for
  merging back into prompt data for ROPD/SFT.
- `manifest.json`: non-secret collection settings.

To merge collected tau2 teachers into new prompt data:

```bash
python examples/agent_env/tau2/prompt_data.py \
  --output /path/to/tau2_prompt_with_teachers.jsonl \
  --teacher-jsonl /path/to/teacher.jsonl \
  --source areal_synthetic
```
